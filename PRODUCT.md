# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Minecraft resource pack creators and shader developers designing custom text effects, HUD elements, or custom font glyphs.

## Product Purpose
Provide zero-setup browser-based testing and previewing for Minecraft core text shaders and font atlases without constantly relaunching or reloading Minecraft in-game.

## Positioning
An instant, client-side preview canvas and shader workbench faithful to Minecraft's GLSL text rendering pipeline and font glyph atlas format.

## Operating Context
Developing and testing Minecraft resource packs, editing font definitions and textures, tweaking custom text core shaders, verifying glyph spacing, shadows, and color codes in real-time.

## Capabilities and Constraints
- Pure client-side web application running entirely in the browser (static hosting, zero backend).
- Resource pack zip loading and asset parsing via fflate.
- Real-time WebGL rendering matching Minecraft vanilla shader pipeline and legacy formatting codes.
- Font atlas previewing, scratch shader editor, and fallback font glyph support.

## Product Principles
- Instant feedback loop over in-game reload cycles.
- High fidelity to Minecraft vanilla shader and font atlas behavior.
- Fully local, zero-friction client-side workflow.
